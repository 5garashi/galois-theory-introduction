# ガロア理論入門

このリポジトリは、ガロア理論の初心者向け資料
「なぜ一般の5次方程式にはべき根による解の公式がないのか」
を公開・更新するためのものです。

## 資料の目的

本資料は、厳密な証明を目的とした専門書ではなく、
ガロア理論の入口を直観的に理解するための入門資料です。

主なテーマは次の通りです。

- ガロア群を、根から作った有理式の値の関係を保つ「許される入れ替え」として見る
- 体が拡大すると、許される入れ替えが減ることを見る。すなわち群は縮小する
- 体の拡大で添加する元の根号の次数nを、その共役元の個数(n)として見る。共役元は360°をn等分する位置に並ぶ
- 方程式がべき根で解ける条件を、{e}まで届く群の縮小鎖として見る
- 一般の5次方程式で何が壁になるのかを見る
